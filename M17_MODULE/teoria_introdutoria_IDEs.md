# Teorias Introdutórias - Python para Analistas [Integrated Development Environment]

## O que é uma IDE?

Um 'Ambiente de Desenvolvimento Integrado' é um programa que vai reunir as ferramentas necessárias para escrever, executar, testar e depurar o código em uma única interface. Normalmente ela inclui:

+ Editor de código com destaque de sintaxe e autocomplete.

+ Execução do programa com um clique.

+ Depurador com pontos de interrupção e inspeção de variáveis.

+ Navegação entre arquivos e projetos.

+ Integração com Git, gerenciador de pacotes e ambientes virtuais.


**Exemplos:**

Para IDEs, temos PyCharm, VS Code, Eclipse, IntelliJ IDEA, Spyder.


## Qual a diferença entre IDE e o Terminal?

O terminal é uma interface puramente de texto, onde você digita comandos para o Sistema Operacional. Ele não é um ambiente de programação em si, apenas permite dar ordens ao computador e traduz o código que você escreve em outro editor. A IDE é uma ferramenta exclusivamente focada em desenvolvimento, que inclusive costuma incluir um terminal embutido. 

**Conclusão:**
A IDE não substitui o terminal, mas o envolve com ferramentas e recursos extras valiosos.

### IDE (Integrated Development Environment)
***Vantagens:***
*Reúne tudo em um lugar só, acelerando o trabalho e facilitando encontrar erros, ajuda a organizar projetos grandes e é mais amigável para iniciantes.*

***Limitações:***
*É mais pesada e consome mais memória, exige intalação e configuração, pode não estar disponível em servidores remotos sem interface gráfica e o excesso de recursos pode atrapalhar quem está começando, escondendo o código real.*


### Terminal (CMD ou Linha de Comando)
***Vantagens:***
*É leve, rápido e funciona em praticamente qualquer máquina, inclusive via SSH, permite automatizar tarefas com scripts, combina comandos entre si e da um contorle preciso sobre o que está sendo executado.*

***Limitações:***
*Sua curva de aprendizado inicial, pois é preciso decorar diversos comandos, não possui depuração visual nem autocompletar, é menos intuitivo para navegação em projetos grandes, erros de digitação são mais problemáticos, como a exclusão de arquivos importantes por engano.*
